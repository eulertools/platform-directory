# platform-directory

Cognito directory / identity CDK (accounts, profiles, alerts, subscriptions). Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/platform-directory-archive`.

Generated `cdk.context.json` (pox.me hosted-zone lookup) was **removed**.

No contract deployments recorded in this repo.

## What was built (EN)

platform-directory provisions the user identity and directory management layer for the Euler platform: Cognito user pools, Lambda authorizers, accounts/profiles/alerts/notifications/subscriptions APIs, and Cognito trigger templates.

## Qué se construyó (ES)

Directorio de identidad (Cognito) de la plataforma Euler. Contexto CDK de AWS eliminado.
